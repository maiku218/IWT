1. CRITICAL BUGS (Must Fix Before Deploy)

BUG-001: Missing psycopg driver on Render
- File: requirements.txt
- Error: ModuleNotFoundError: No module named 'psycopg'
- Cause: SQLAlchemy 2.x requires psycopg v3 driver, but only psycopg2-binary was listed
- Fix: Added psycopg==3.2.3 to requirements.txt (commit 66d4c38)
- Status: FIXED

BUG-002: Wrong gunicorn start command on Render
- Error: AttributeError: module 'app' has no attribute 'app'
- Cause: Start command was `gunicorn app:app` but entry point is run.py
- Fix: Changed to `gunicorn run:app` in Render dashboard
- Status: FIXED (dashboard setting)

BUG-003: No database migration on Render deploy
- Error: Tables missing on first deploy, causing 500 errors
- Cause: flask db upgrade not run automatically
- Fix: Added auto-migration + admin seeding in run.py (commit 2ec409c)
- Status: FIXED

BUG-004: CSRF token not sent on work log delete

BUG-005: Calendar events API date format crash
- File: app/routes/dashboard.py
- Error: ValueError: unconverted data remains: T00:00:00+08:00

- Status: FIXED

BUG-006: Work log time fields removed but code still references them
- File: app/models.py, work_logs.py, templates

- Status: FIXED

3. MEDIUM PRIORITY BUGS
============================================

BUG-007: Timezone mismatch on Windows (naive vs aware datetime)
- File: app/routes/attendance.py, app/models.py
- Error: TypeError: can't compare offset-naive and offset-aware datetimes
- Cause: PostgreSQL stores naive timestamps, Python uses timezone-aware UTC
- Fix: Changed to datetime.utcnow() (naive UTC) consistently; added .replace(tzinfo=timezone.utc) for Manila conversion
- Status: FIXED

BUG-008: Attendance status property called as method
- File: app/models.py, app/routes/attendance.py
- Error: TypeError: 'property' object is not callable
- Cause: attendance_progress and completed_hours are properties but called with ()
- Fix: Removed () calls
- Status: FIXED

BUG-009: jsonify with status code as second argument produces wrong output
- File: app/routes/attendance.py
- Error: Returns JSON array instead of error object with 400 status
- Cause: jsonify({"error": "..."}, 400) creates array [{"error": "..."}, 400]
- Fix: Changed to jsonify({"error": "..."}), 400
- Status: FIXED

BUG-010: filter_by after join causes ambiguous column error
- File: app/routes/admin.py
- Error: sqlalchemy.exc.AmbiguousForeignKeysError or InvalidRequestError
- Cause: filter_by(request_status=...) after join doesn't know which table
- Fix: Changed to filter(AttendanceCorrectionRequest.request_status == ...)
- Status: FIXED

BUG-011: _audit() called with wrong arguments
- File: app/routes/admin.py
- Error: TypeError: _audit() got unexpected keyword argument
- Cause: _audit signature doesn't match calls (attendance_id, admin_id, etc.)
- Fix: Changed to _audit(action, target_type, target_id, details) format
- Status: FIXED
